# Architecture Decision Records — index

Nygard-lite format, see `template.md`; the policy is [ADR 0000](0000-use-adrs.md). Numbers have no
gaps and are never reused: a new ADR always takes the next number, and an existing file is never
overwritten, renamed or deleted. A decision that no longer holds gets `Superseded by` (or a note) in
its `Status`, not a removal. Check with `make adr-check`.
